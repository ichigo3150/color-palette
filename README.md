# color-palette

色の系統ごとに50段階の色を並べた、絵の具パレット風のカラーコード見本アプリです。

## 使い方

- 左右にスワイプ（または上のタブ・矢印キー・前へ／次へボタン）で色の系統を切り替えます
- 色をクリック（タップ）すると、そのカラーコード（例：`#FF0000`）がコピーされます
- 系統は 赤・オレンジ・黄・緑・シアン・青・紫・ピンク・茶・グレー の10種類です

## 動かし方

`index.html` をブラウザで開くだけで動きます。インストールは不要です。

GitHub Pages で公開すると、URLを送るだけで誰でもスマホやパソコンから使えます。
